# 深度与宽度取舍

- 深度：编码器或解码器块的数量

- 宽度：嵌入 (embedding)维度（d_model）、以及位置前馈网络中的中间维度（d_ff）

- 增加深度意味着：让模型进行更多次加工（思考步骤更多），能提升推理能力。

- 增加宽度意味着：每个token可以携带更多的信息（相当于容量更大），能存储更多的信息。

一般情况是两者同时增加

# 前馈网络中的激活函数选择

- ReLU： 简单、稀疏、计算快。存在死神经元问题，梯度在负区为 0
- GELU： 平滑、近似 ReLU 。比 ReLU 更好的梯度流，计算稍贵
- SwiGLU：引入了门控，可能对信息流动提供更好的控制。

# 规范化层（Normalization Layer）的放置位置

主要争论集中在 Post-LN 与 Pre-LN 两种方式。

### Post-LN（原始 Transformer，Vaswani et al., 2017）

先做 Attention 、FFN，再与残差相加，最后做规范化。残差路径上有 LN，会干扰梯度直接回传。

```
                x_l
                  |
                  |
                  |
                  v
          +---------------+
          |   Attention   |
          |    or FFN     |
          +---------------+
                  |
                  |
                  v
               F(x_l)
                  |
                  |
                  |
x_l --------------+
                  |
                  v
              +-------+
              |  Add  |
              +-------+
                  |
                  |
                  v
              +-------+
              |  LN   |
              +-------+
                  |
                  |
                  v
              x_{l+1}
```

### Pre-LN（现代主流）

先对输入做规范化，再进入子层（Attention、FFN），最后与残差相加。残差主路径保持“干净”，梯度可直接通过残差连接回传。

```
                 x_l
                  |
                  |
                  |
                  v
              +-------+
              |  LN   |
              +-------+
                  |
                  |
                  v
          +---------------+
          |   Attention   |
          |    or FFN     |
          +---------------+
                  |
                  |
                  v
              F(LN(x_l))
                  |
                  |
                  |
                  v

x_l ------------------------------+
                                  |
                                  v
                              +-------+
                              |  Add  |
                              +-------+
                                  |
                                  |
                                  v
                              x_{l+1}
```

# 稀疏注意力机制

标准自注意力机制（Standard Self-Attention）的计算复杂度和显存占用随着序列长度 N 呈平方级增长（即 O(N^2)）

稀疏注意力机制（Sparse Attention）的核心思想是：**打破“所有 Token 必须与所有其他 Token 进行计算”的完全连接假设**，只让每个 Token 与一小部分高度相关的 Token 产生连接，从而将复杂度降。


# 初始化方法

神经网络刚开始训练时，权重应该设置成多大？

### Xavier（Glorot）初始化

- 适合 tanh、sigmoid、softsign 等关于原点对称的激活函数。

- 对 ReLU 系列激活函数效果一般


假设：

```
1.输入 x是独立同分布 (i.i.d.) 的，均值为零，方差为Var(x)
2.输入 W是独立同分布 (i.i.d.) 的，均值为零，方差为Var(w)
3.权重和输入相互独立
4.希望信号经过一层之后，方差不要发生巨大变化，也就是 Var(y) ≈ Var(x) 方差保持。
```

核心公式：

```
z = w₁x₁ + w₂x₂ + ... + wₙxₙ
z = Σᵢ wᵢxᵢ
Var(z)= Σᵢ Var(wᵢxᵢ)
Var(z) ≈ fan_in · Var(w) · Var(x)
```

希望：

```
Var(z) ≈ Var(x)
```

Xavier 的核心方差:

```
Var(W) ≈ 2 / (fan_in + fan_out)
```

Xavier Uniform:

```
W ~ U(-a, a)

a = √(6 / (fan_in + fan_out))
```

Xavier Normal：

```
W ~ N(0, σ²)

σ = √(2 / (fan_in + fan_out))
```

fan_in fan_out 是神经元输入输出数量

### Kaiming（He）初始化

前提假设:

```
1.输入 x是独立同分布 (i.i.d.) 的，均值为零，方差为Var(x)
2.输入 W是独立同分布 (i.i.d.) 的，均值为零，方差为Var(w)
3.w和x相互独立
```

解决 Xavier 初始化在面对 ReLU 激活函数时失效 的问题而诞生的。

解决：神经网络使用 ReLU 时，应该把权重初始化到多大


- 在 Xavier 中，为了保持方差不变，权重的方差要求是：Var(W) = (1)/(n) （n 是输入节点的数量，即 fan_in）

- 在 Kaiming 初始化中，由于 ReLU 的存在，权重的方差要求变成了原来的 2倍：Var(W) = (2)/(n) = (2)/(fanᵢn)

推导过程：

```
y = w₁x₁ + w₂x₂ + ... + wₙxₙ
y = Σᵢ wᵢxᵢ
Var(y)= Σᵢ Var(wᵢxᵢ)
Var(y) ≈ fan_in · Var(w) · Var(x)
```

现在经过 ReLU：

```
z = ReLU(y)
```

由于一半y都会被设置为0，可以粗略理解为

```
Var(z) ≈ 1/2(Var(y))
```

```
Var(z) ≈ 1/2(fan_in · Var(w) · Var(x))
```

令

```
Var(z) ≈ Var(x)
```

得到：

```
Var(w) = 2/fan_in
```

### Transformer中的组件初始化

| 组件                    | 常用初始化       | 典型标准差 | 备注                           |
| ----------------------- | ---------------- | ---------- | ------------------------------ |
| **Token Embedding**     | Normal           | 0.02       | 最常见                         |
| **Position Embedding**  | Normal / 0       | 0.02 或 0  | 绝对位置常用 0.02，RoPE 无参数 |
| **Attention Q/K/V/O**   | Normal           | 0.02       | 几乎所有大模型都用这个         |
| **FFN (up & down)**     | Normal           | 0.02       | 同上                           |
| **Output Head**         | Normal           | 0.02       | 有时会特殊处理                 |
| **LayerNorm / RMSNorm** | weight=1, bias=0 | -          | 几乎固定                       |
| **Bias**                | 全部置 0         | -          | 标准做法                       |

# 参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）

思想：冻结预训练模型的大部分（或全部）原有权重，只在模型中添加或选择极少量的参数进行训练。这样只需微调 0.1% 到 3% 的参数，就能达到与全量微调相近的效果。

### 低秩适配LoRA（Low-Rank Adaptation）

大模型内部全是一个个巨大的权重矩阵（比如 W）。

在微调时，我们的目标是找到一个最优的参数更新量（我们叫它 Δ W），使得新模型权重 W_{new} = W + Δ W。

在全量微调中，Δ W 的尺寸和原矩阵 W 一模一样巨大。

**LoRA 的核心假设是（低秩假设）：模型在适应特定下游任务时，真正需要改变的特征维度其实非常少。** 也就是说，Δ W 是一个“低秩”（Low-Rank）矩阵，它包含大量冗余信息。

既然不需要那么多维度，LoRA 就用**两个小矩阵相乘**来近似模拟这个大矩阵 Δ W：

Δ W = A × B 

- * 假设原矩阵 W 是 10000 × 10000 的维度（总计 1 亿个参数）。

- * 我们设定一个很小的数字，叫做 **秩（Rank，用 r 表示）**，比如 r = 8。

- * 那么矩阵 A 的维度就是 10000 × 8；矩阵 B 的维度就是 8 × 10000。

- * A 和 B 加起来的参数量是 8万 + 8万 = 16 万个。

**参数量直接从 1 亿骤降到 16 万，减少了 99.8%！** 这就是 LoRA 能够用极低显存完成微调的根本原因。

# 优化算法

### 自适应优化器：Adam和AdamW

##### 背景：为什么需要自适应优化器？

在标准的随机梯度下降（SGD）中，所有的参数都共享同一个全局学习率（Learning Rate）。然而，在复杂的神经网络中，不同参数的梯度可能有极大的差异：
* 常见特征的参数可能频繁更新，梯度较大。
* 罕见特征的参数更新不频繁，梯度较小。

如果统一使用相同的学习率，可能会导致常见特征的参数在最优解附近震荡（学习率太大），而罕见特征的参数收敛极其缓慢（学习率太小）。**自适应优化器（Adaptive Optimizers）**的核心思想就是：**根据参数的历史梯度信息，为每个参数动态调整（自适应）独立的学习率。**
